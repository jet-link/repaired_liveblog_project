{% comment %} Adaptive image grid for theme cards. Layout rules (driven entirely by ``data-count`` on the wrapper, no JS needed): * 1 image → single image, capped height, full card width. * 2 images → two equal columns side-by-side. * 3 images → first image is the tall "hero" on the left, the other two stack on the right (Twitter-like). Each ships a ``srcset`` of thumbnail/medium/large WebP variants so the browser can pull the cheapest one that fits the rendered slot, and is set to ``loading="lazy"`` + ``decoding="async"`` so off-screen feed cards never block first paint of the page. {% endcomment %}
